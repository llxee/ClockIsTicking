# Clock 

## 🌟 主要功能

  - 指定监控目标程序后仅当目标窗口确实处于前台获取系统焦点，并且用户为非闲置状态（即10分钟内存在键鼠标交互）时，才会进行计时。
  - 设置中可按需配置您的“专注循环时间”（默认 60 分钟/段）。时间达标后当前钟自动重置，自增 **循环计数** ，并汇入 **总计时间** 里供以后查阅。
  - 提供顶部快捷入口，设置诸如重要考试、交付发版日等未来的目标日期。 
  - 通过左下角的🚥指示灯提供工作态反馈，绿色代表正在计时，黄色代表已暂停（例如切换到非目标程序或用户闲置）
  - 基于.NET 8 Wpf Desktop 构建，依赖于.net 8运行时，如无法运行请先安装：https://dotnet.microsoft.com/en-us/download/dotnet/8.0

## 🚀 极速上手

1. 运行项目，可以通过右下角切换您喜欢的深色或浅色模式色调。
2. 点击左上角的 **"⚙️ 设置"**：
    - 点击 **"添加当前 Focus 窗口(倒数5s)"**，然后在限期内马上切回（点击）你想监控的主力软件，直至看见文字恢复原始状态，该软件进程窗口就会自动被添加。
    - 也可以在旁边的下拉框手选。
3. 如果你定下了每日工作 X 小时目标，可配置“循环时间”设定为对应的段落，点击 **“关闭设置”**。
4. 现在，当你把窗口焦点落在目标程序上工作时，左下角指示灯变绿开始计时，摸鱼或最小化时会自动暂停。
