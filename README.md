# Clock Is Ticking

一个基于 WPF 和 .NET 8 开发的现代化桌面计时与专注度统计工具。它可以追踪特定目标应用程序的焦点状态，并统计您的有效专注时间。

## ?? 主要功能

- **?? 专注窗口智能监控**
  - 指定监控目标程序。
  - **精确计时**：仅当目标窗口确实处于前台获取系统焦点，并且用户为非闲置状态（即10分钟内存在键鼠标交互）时，时钟才会滴答作响。
  - **多模式添加捕捉**：不仅可以通过下拉列表浏览当前可见的主窗口，还提供 **5秒延时倒数捕捉法** —— 点击倒数按钮并在倒数结束前切换至你需要投入工作的全屏/前台软件即可自动拾取。
  - 底层基于**类名与进程名**作为唯一凭证进行跟踪，无视由于网页切换或文件名称变动导致的标题变化，全程无缝监控。

- **?? 分段循环与总计**
  - 超大数字主时钟界面，直观展现当前正在进行的 Session 时间。
  - 可视化循环控制：设置中可按需配置您的“专注循环时间”（默认 60 分钟/段）。时间达标后当前钟自动重置，自增 **循环计数** ，并汇入 **总计时间** 里供以后查阅。完全适配个人习惯的番茄工作流。

- **?? 目标日倒计时**
  - 提供顶部快捷入口，设置诸如重要考试、交付发版日等未来的目标日期。 
  - 常驻显示“目标日倒计时: X 天”，每天深夜零点自动扣减。

- **?? 现代化界面设计**
  - **Fluent 沉浸式风格**：半透明无边框圆角窗口，顶部的窗口控制按钮仅在鼠标悬浮时展示，极具现代清爽感。支持鼠标直接拖拽移动位置。
  - **状态提示灯**：通过左下角的??指示灯提供工作态反馈（?? 表示暂停或不在目标窗口/人不在电脑前；?? 表示状态符合要求，计时正在狂奔）。
  - **昼夜双模**：支持全局白天/黑夜主题界面一键切换。 
  - **防误关守护**：当积累连续超过 1 小时专注时刻准备退出程序时，贴心拦截并进行二次确认提示。

- **?? 数据持久化记忆**
  - 自动备份所有数据（包括配置循环、当前未结算时间、添加关注了哪些进程、制定的倒数目标日），序列化为 `save.sv`。再次打开应用无缝衔接。

## ??? 技术相关

- **目标框架**: .NET 8 Wpf Desktop
- **UI 及架构解耦**: MVVM (利用 `CommunityToolkit.Mvvm` 源生成与数据绑定)
- **底层驱动**: Windows Win32 API (`User32.dll` 下的 GetForegroundWindow, EnumWindows, GetLastInputInfo 等方法提供低级全局系统事件探引)

## ?? 极速上手

1. 编译并运行项目，可以通过右下角切换您喜欢的深色或浅色模式色调。
2. 点击左上角的 **"?? 设置"**：
    - 点击 **"添加当前 Focus 窗口(倒数5s)"**，然后在限期内马上切回（点击）你想监控的主力软件（例如 IDE, Word 等等），直至看见文字恢复原始状态，该软件进程就会自动被添加。
    - 也可以在旁边的下拉框手选。
3. 如果你定下了每日工作 X 小时目标，可配置“循环时间”设定为对应的段落，点击 **“关闭设置”**。
4. 现在一切就绪！当你把窗口焦点落在目标程序上工作时，左下角指示灯变绿开始倒数。摸鱼或最小化时会自动暂停！
